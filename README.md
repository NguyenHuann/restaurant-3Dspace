# Không Gian Nhà Hàng 3D (3D Restaurant Space)

Dự án Đồ họa máy tính xây dựng không gian nhà hàng phong cách Diner 3D tương tác, lập trình bằng C++ với thư viện OpenGL và GLUT. Tác giả: Nhóm 8 - 23CN1

---

## Hướng Dẫn Điều Khiển (Controls)

Chương trình hỗ trợ chế độ góc nhìn thứ nhất (First-Person Camera) cho phép tự do đi lại và khám phá toàn cảnh không gian, kết hợp cùng các phím tương tác môi trường.

### Điều khiển bằng Chuột

| Thao tác                             | Chức năng                                       |
| :----------------------------------- | :---------------------------------------------- |
| **Giữ Chuột Phải + Di chuyển chuột** | Xoay góc nhìn Camera (Nhìn lên/xuống/trái/phải) |

### Điều khiển bằng Bàn phím

#### 1. Di chuyển Camera (Chế độ tự do)

| Phím  | Hành động                     |
| :---: | :---------------------------- |
| **W** | Tiến tới trước                |
| **S** | Lùi về sau                    |
| **A** | Di chuyển sang trái           |
| **D** | Di chuyển sang phải           |
| **E** | Di chuyển lên trên (Trục Y)   |
| **R** | Di chuyển xuống dưới (Trục Y) |

#### 2. Tương tác & Hệ thống

|  Phím   | Hành động                                                      |
| :-----: | :------------------------------------------------------------- |
|  **G**  | Bật / Tắt hiệu ứng quạt trần quay                              |
|  **F**  | Bật / Tắt chế độ Camera tự động xoay (Rotate Around Cinematic) |
| **ESC** | Thoát chương trình một cách an toàn                            |
